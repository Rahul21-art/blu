🎯 Option 1: Auto-Rig with Mixamo (Free, 10 min)

Step 1 — Export your model as FBX

Open your model in Blender (free) or any 3D software.

  • File → Export → FBX (.fbx)
  • Settings: Version: FBX 7.4 binary
  • Check: Include: Selected Objects
  • Path mode: Copy
  • Save as blu.fbx
💡 If you don't have Blender, download it from blender.org (free).

Step 2 — Upload to Mixamo

Go to mixamo.com and sign in with an Adobe account (free tier available).

  • Click "Upload Character"
  • Select your blu.fbx
  • Wait for auto-rigging (usually 10-30 seconds)
  • Place markers on joints if prompted → click "Next"
  • Click "Auto-Rig"

📁 Combining Animations with GLB

Step 1 — Import into Blender

Open Blender. Import your original blu.fbx or blu.glb.

Step 2 — Add Mixamo Animations

In Blender:

  • Import each anim_*.fbx from Mixamo
  • They auto-attach to the skeleton if the names match
  • Rename animations: Idle, Walk, Run, etc.

Step 3 — Export as GLB

File → Export → glTF 2.0 (.glb)

  • ☑ Include: Selected Objects
  • ☑ Include Animations
  • ☑ Use Blender (Bake) Skin
  • Save as blu.glb
  • Replace assets/blu.glb
💡 The code auto-detects animations! If animations are found, real animation mixer takes over. If not, procedural fallback runs.
